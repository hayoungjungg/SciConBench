    Data + Method

    SciConBench contains more than 9,000 questions derived from Cochrane systematic reviews, each paired with an expert-written conclusion. Conclusions are decomposed into atomic, checkable facts so model responses can be evaluated (see “Quantitative Results” below).

    The dashboard uses a live evaluation panel drawn from this benchmark: a fixed core supports consistent comparisons, while monthly rolling cohorts add newly published reviews. The full benchmark is available on Hugging Face.

    The full benchmark is published on HuggingFace. The figures below describe the live evaluation panel — the subset every tracked model is re-run against each month. A frozen core sample keeps month-to-month comparisons stable, and each monthly rolling cohort adds reviews no model could have seen during training.

    How scoring works

    Long-form conclusions can't be graded by string match. SciConBench grades them fact by fact.

    Factual precision

    The agent's conclusion is decomposed into atomic facts, and a judge labels each one supported, contradicted, or not supported against the full review. Contradictions are penalized twice — once for not being supported, once for being wrong.

    (supported / total) × ((total − contradicted) / total)
    Factual recall

    The expert conclusion is decomposed the same way, and the judge checks how many of those facts the agent's conclusion actually conveys. This is what separates a confident-sounding summary from a complete one.

    supported expert facts / total expert facts
    Clean room

    All retrieval is proxied. The harness blocks the target review, any document citing it, and anything published after its date, across web search, academic search, and page fetches — so the answer cannot simply be looked up.
